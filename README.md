🛍️ Loja Alelli - Landing Page

Uma página web desenvolvida em HTML5 puro para a loja de moda feminina Alelli. O projeto apresenta a nova coleção da marca, produtos em destaque e um formulário interativo para captação de clientes.

Recursos e Estruturas Utilizadas:
* **HTML5 Semântico:** Estruturação correta com `<header>`, `<main>`, `<section>` e `<footer>` para melhor organização e acessibilidade.
* **Vitrine de Dados:** Uso de listas (`<ul>`) para categorias e tabelas (`<table>`) para exibição de preços.
* **Multimídia:** Player de vídeo integrado (`<video>`) exibindo os desfiles da marca.
* **Formulário de Cadastro:** Área de inscrição de clientes com `<fieldset>`, validações nativas (`required`), restrições numéricas (`min`/`max`) e tipos de input específicos (e-mail, data e número).

**Como rodar o projeto localmente:**
1. Clone este repositório ou faça o download dos arquivos.
2. Certifique-se de que os arquivos de mídia da loja (como `Modelo1.png` e `IMG_4893.MP4`) estão salvos na mesma pasta raiz.
3. Clique duas vezes no arquivo `index.html` para abri-lo diretamente no seu navegador. Nenhuma instalação adicional é necessária!
